HOW I WORK

Build what can be defended.

I care about the difference between a polished interface and a functioning product. My process keeps that distinction visible.

01

Frame

Define the user, business problem, workflow and intended outcome before adding features.

02

Architect

Translate the idea into screens, states, roles, data requirements and product boundaries.

03

Build

Use AI-assisted development, no-code/low-code tools and code workflows to create the product surface.

04

Validate

Test flows, challenge unsupported claims, inspect errors and separate real functionality from planned functionality.
